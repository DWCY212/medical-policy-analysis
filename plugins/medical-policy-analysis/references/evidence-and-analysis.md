# 证据与“政策潜规则”分析规范

## 原因链

围绕每个关键措施回答五个问题：

1. 出现了什么问题：患者、支付方、医疗机构、药品供应或监管环节的可观察问题。
2. 为什么需要处理：问题规模、风险外溢、财政/公平/可及性压力或上位战略要求。
3. 要解决什么问题：政策明确目标与可验证的制度目标。
4. 怎么去解决：对象、资格、支付、供给、监管、数据和考核等工具如何组合。
5. 对业务意味着什么：对连续用药、处方流转、医保结算、药品供应和服务流程的影响；区分事实和假设。

## 表述规则

每个结论使用一个且仅一个性质标签：

| 标签 | 使用条件 | 写法要求 |
| --- | --- | --- |
| `[官方明确表述]` | 原文或官方解读直接说出原因、目标或机制 | 引用文件标题、条款/段落和 URL |
| `[多来源支持的判断]` | 至少两个独立资料相互印证 | 列出每个来源，不把相关性写成因果确定性 |
| `[基于政策演进的推断]` | 由时间、范围、工具变化推断 | 说明推断链和支撑文件 |
| `[待验证假设]` | 业务上合理但资料尚不足 | 另起一行，写明需要的统计、访谈或文件 |

新闻、统计、论文和行业资料用于补充背景或验证，不替代政策原文。允许讨论政策出台前的问题，但不得声称国家“意图”除非有官方证据；没有证据时改写为“可能的制度动因”并标为推断或假设。

## 审核清单

- 官方意图、判断、推断和假设分开。
- 每一个关键判断可追溯到来源编号或 URL。
- 同一政策在不同来源的日期、文号、标题一致；冲突单列。
- 没有把“相关”写成“导致”，没有把试点效果外推为全国效果。
- 所有待确认文件、转载和失效网址在最终文档中保留，不静默删除。
