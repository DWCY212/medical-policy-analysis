# 五份文档模板

生成时保留这些一级标题；可以增加小节，但不要删除来源、核验和待确认栏目。文档开头写入生成时间、任务标识、所依据的上游版本和 `人工确认内容` 标记（无人工确认时写“无”）。

## 01-政策理解.md

```markdown
- 依据版本：
- 人工确认内容：无/有（说明文件和段落）

| 官方标题 | | |

| 行政层级 | | |
| 发布日期 | | |
| 文号 | | |
| 官方来源网址 | | 原文/转载/待确认文件/需人工审核 |

## 二、政策对象与核心内容
## 三、政策工具与执行要求
## 四、用户文件与官方信息差异
## 五、待确认项与核验动作
## 六、资料清单
```
