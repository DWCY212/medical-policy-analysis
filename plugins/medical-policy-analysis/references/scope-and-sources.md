# 范围与官方来源规则

## 业务范围

| 维度 | 规则 |
| --- | --- |
| 地域 | 中国大陆；港澳台不纳入，除非用户明确要求作对比且单独标注 |
| 层级 | 国家、省、市三级；国家和省级重点，市级补充 |
| 部门 | 医保局、卫生健康委、药监局为核心；其它仅纳入国家级和省级且与医疗强相关的部门 |
| 文件 | 规范性文件、规划、通知、意见、办法、细则、公告、答复、政策解读和强相关地方试点 |
| 排除 | 医院内部制度、无法证明与主政策相关的宣传稿、纯商业材料 |
| 时间 | 主政策发布日往前五年至当前日；主政策发布日之后一直检索到当前日 |

## 官方来源优先级

1. 原发布机关的政府网站或部门官网。
2. 中国政府网、国务院部门网站、国家级直属机构官网。
3. 省、市人民政府网站及其部门官网。
4. 政府网站转载页：可以引用，但在“来源类型”写 `转载`，并记录转载机关；同时继续查找原始发布页。若最终找不到原始发布页，仍保留 `转载`，不得改写成原文。
5. 政策数据库、商业数据库、搜索摘要：只能作为检索线索，不能作为最终出处。

“政府网站”包括以政府机关域名和政务公开栏目发布的页面。遇到 PDF、扫描件或网页失效时，记录可访问的官方索引页、文件标题和核验日期；原文无法验证时标记 `需人工审核`。

## 核验字段

每份文件建立一行记录，至少包含：

| 字段 | 填写要求 |
| --- | --- |
| 文件标题 | 使用官方页面标题；用户文件可另列“用户提供标题” |
| 发布机关 | 具体到国家/省/市及部门 |
| 行政层级 | 国家、省、市 |
| 发布日期 | 统一为 `YYYY-MM-DD`；只有年月时保留精度并说明 |
| 文号 | 原文中的发文字号；没有文号写“未载明” |
| 官方来源网址 | 原文 URL；找不到写“待确认文件” |
| 来源类型 | 原文、转载、待确认文件、需人工审核 |
| 核验日期 | 本次检索日期 |
| 关联理由 | 与主政策的条款、对象、药品/支付/服务环节或演进关系 |

禁止根据相似标题推断文号或日期。页面内容与 PDF 内容冲突时，以原发布机关的正式 PDF/公告为准，并在备注中说明冲突。用户文件找不到原文时，后续引用使用“（待确认文件）”，官方来源网址字段写“待确认文件”。

## 检索记录

在最终文档中保留检索范围、关键词、访问日期、未纳入的近似文件及排除理由。对失效网址和待确认文件给出人工核验动作，例如“到发布机关站内搜索完整标题或文号”。
