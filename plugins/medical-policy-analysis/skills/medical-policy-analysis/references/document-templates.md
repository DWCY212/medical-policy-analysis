# 五步输出模板

第一、三、四、五步输出 Markdown；第二步输出 Excel。所有 Markdown 在开头记录生成时间、任务标识、依据版本、联网核验日期和人工确认内容。

## 01-政策理解.md

```markdown
# 政策理解：{主政策标题}

## 文档元信息
- 生成时间：
- 联网核验日期：
- 依据版本：
- 人工确认内容：无/有

## 一、政策身份与官方来源核验
| 字段 | 结果 | 核验说明 |
| --- | --- | --- |
| 官方标题 | | |
| 管辖地区 | | |
| 发布机关 | | |
| 行政/监管层级 | | |
| 发布日期 | | 官方页面、公报或索引显示日期；与正文落款不一致时在此说明 |
| 文号/文件编号 | | |
| 官方来源网址 | | 原文/转载/待确认文件/需人工审核 |

## 二、政策对象与适用范围
## 三、核心措施与执行机制
## 四、用户文件与官方信息差异
## 五、待确认项与核验动作
## 六、资料来源
```

## 02-相关政策.xlsx

按 [excel-output.md](excel-output.md) 创建真正的 Excel 工作簿。不得输出同名 Markdown 代替。核心政策表只收录强相关文件，中等相关背景和排除项单独记录。

## 04-初步分析.md

编号严格按用户指定保留，不自行补写“七”。

```markdown
# 初步分析：{主政策标题}

## 文档元信息

## 一、政策研究后的核心结论
## 二、政策原文能够直接确认的内容
## 三、政策出台背后问题的推理
## 四、政策要解决的 {X} 个层次
## 五、政策采用的解决路径
## 六、对产品设计的业务启示
### 1. 产品定位
### 2. 建议的建设优先级
## 八、结论与方向判断
## 九、资料来源汇总
```

将 `{X}` 替换为证据支持的实际层次数字，不在交付文档中保留占位符。

每个推理段落使用证据标签。建设优先级至少说明政策确定性、用户问题紧迫性、能力复用性、数据依赖、实施成本与合规风险。
