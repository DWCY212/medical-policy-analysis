# 范围、相关性与官方来源规则

## 动态业务范围

| 维度 | 规则 |
| --- | --- |
| 地域 | 分析范围不限于中国；以主政策适用的国家或地区为核心，跨地区材料仅在可比较且强相关时纳入 |
| 层级 | 中国使用国家、省、市；其它管辖地区映射为中央、区域、地方或其法定等效层级 |
| 部门 | 中国重点检索医保局、卫生健康委、药监局；其它地区检索医疗支付、卫生行政、药品监管等效机关 |
| 时间 | 不使用固定前后五年窗口；围绕强相关政策追溯问题来源、制度前身、配套执行和后续调整 |
| 文件 | 法律法规、正式政策、规划、通知、意见、办法、细则、公告、官方解读、答问和强相关试点 |
| 排除 | 医院内部制度、纯商业宣传、无法证明关联的材料、只有搜索摘要而无可核验正文的线索 |

先界定主政策的管辖地区，再决定检索层级和机关。跨国或跨地区政策不得直接混入同一演进链，除非明确标为比较材料并说明制度可比性。

## 强相关性判断

相关性优先于时间距离。核心表只纳入满足以下任一直接关系的政策：

- 明确引用、依据、废止、替代、修订、延续或落实主政策；
- 面向相同政策对象，并使用相同或相互衔接的支付、准入、处方、供应、监管、数据或考核工具；
- 属于主政策的上位依据、配套细则、执行通知、试点前身或后续调整；
- 能解释同一问题如何出现、发酵、进入议程并转化为治理措施。

在工作簿中把相关性写为：

- `强-直接制度关系`：存在引用、上下位、替代、配套或实施关系。
- `强-同一问题链`：对象、问题和核心政策工具高度一致，能够进入同一演进链。
- `中-背景补充`：只用于解释背景，不进入核心演进阶段。
- `弱-排除`：仅主题相似，无足够制度或问题链关系，放入排除表。

不得为了增加数量纳入中弱相关政策。没有固定文件数量要求。

## 官方来源优先级

1. 原发布机关官网、官方公报、法定法规数据库或正式文件附件。
2. 同一政府体系的中央或地方政府门户、议会或法定机构官网。
3. 政府或主管机关转载页；来源类型标记 `转载`，继续寻找原始页面。
4. 政策数据库、媒体、论文、行业资料和搜索摘要；只作检索线索或背景资料，不作为政策原文的最终出处。

不同管辖地区使用其等效官方体系，不以域名后缀单独判断官方性。记录发布主体、页面归属和核验日期。

## 日期定义

`发布日期` 是官方网页、官方公报目录或官方索引页显示的文件发布日期，也是文档和 Excel 中唯一的日期字段。统一为 `YYYY-MM-DD`；只有年月时保留原精度并说明。正文落款日期通常与官网日期一致，不再单列；少数不一致时，以官网显示日期作为 `发布日期`，把正文落款日期和差异写入备注。

不得使用搜索结果日期、网页抓取日期、下载日期或 PDF 文件属性代替发布日期。官网只显示更新时间时，将其写入备注，不擅自视为首次发布日期。

## 核验字段

每份政策记录至少包含：

| 字段 | 填写要求 |
| --- | --- |
| 政策标题 | 使用官方页面或正式正文标题 |
| 管辖地区 | 国家或地区，以及必要的省州、区域或城市 |
| 发布机关 | 使用机关正式名称 |
| 行政/监管层级 | 国家/中央、省州/区域、市/地方或等效层级 |
| 发布日期 | 按上节定义填写 |
| 文号/文件编号 | 原文载明；没有则写 `未载明` |
| 官方来源网址 | 原始官方 URL；找不到写 `待确认文件` |
| 来源类型 | 原文、转载、待确认文件、需人工审核 |
| 关联强度 | 强-直接制度关系、强-同一问题链、中-背景补充、弱-排除 |
| 关联理由 | 说明对象、问题、工具、上下位或演进关系 |
| 核验日期 | 本次实际联网核验日期 |

标题、日期、文号冲突时并列证据。优先正式文件正文和原发布机关页面，不根据相似文件猜测缺失字段。

## 检索记录

记录管辖地区、机关、检索式、检索日期、命中页面、纳入状态和排除理由。最终文档和 Excel 必须保留失效网址、转载、待确认文件及人工核验动作。
